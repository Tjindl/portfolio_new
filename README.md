# Portfolio (Vite + React + three.js)

A starter portfolio with a 3D interactive hero using react-three-fiber and drei.

Setup

1. cd into the project
2. npm install
3. npm run dev

Notes

- The 3D hero is a torus knot as a placeholder. Replace it with a glTF model using @react-three/drei's useGLTF when ready.
- Tune dependencies to latest versions as needed.
